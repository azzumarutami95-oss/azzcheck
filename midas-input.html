PROPERTIESGeometry / kolom

Material properties

Elastic material

E dan γ mengikuti satuan gaya/panjang model. Material berbasis database MIDAS dipertahankan melalui MCT; form ini mengedit material elastis USER (DATA1 = 2).

Element properties

Klik elemen pada model 3D, atau masukkan ID elemen BEAM.

Supports / boundary

Centang DOF untuk menahan geraknya. Free menghapus constraint pada node terpilih; rigid link dan pegas tetap terpisah.

Nodal loads

Global force / moment

Satuan gaya dan momen mengikuti model. Apply mengganti beban nodal pada ID node dan load case ini, termasuk entri kelompok beban. Tidak mendistribusikan beban ke kolom lain.

Linked parameters

Z atas = Z dasar + H. Grid: n = nX × nY. Semua posisi diputar terhadap pusat susunan. Edit tabel untuk posisi bebas.

Klik sel untuk mengubah data; pindahkan fokus agar perubahan tersimpan. Gunakan titik untuk desimal. Penambahan/penghapusan baris melalui editor teks.

Editor bagian MCT

Untuk material, penampang, pegas, link, kombinasi, dan data kompleks, ikuti komentar format pada file. Klik Terapkan setelah mengedit teks.

Tampak isometrik 3D

Model 3D berdasarkan koordinat NODE, konektivitas ELEMENT, dan dimensi SECTION. Warna membedakan ID penampang. Seret untuk memutar; Shift + seret untuk menggeser; roda mouse untuk zoom. Pada layar sentuh, seret untuk memutar dan gunakan tombol zoom.

Volume mendukung SECTION DBUSER persegi panjang solid (SB), lingkaran solid (SR), dan tapered SB linear dengan offset pusat CC tanpa pergeseran tambahan. Penampang umum/majemuk, offset selain CC, dan tipe lain tetap berupa garis. Penampang lingkaran didekati 16 sisi. Sumbu lokal mengikuti arah node I–J dan sudut elemen. Tumpuan, beban, rigid link, dan deformasi belum divisualisasikan; tampilan ini untuk pratinjau geometri. Perubahan editor teks harus diterapkan dahulu. Arah sumbu global ditunjukkan di pojok gambar.

Jumlah & posisi kolom

Atur n kolom vertikal dan koordinat tiap kolom. Untuk model contoh, pilih kedua section Kolom P2 - TOP dan Kolom P2 - BOT agar satu kolom mencakup seluruh tingginya. Satuan mengikuti model.

Perubahan n membuat ulang tabel posisi beraturan dari pusat dan jarak di atas. Untuk susunan bebas, edit X, Y, Z dasar, dan Z atas pada tabel. Jumlah n adalah jumlah kolom dalam kelompok section terpilih, bukan jumlah semua elemen vertikal model.

KolomXYZ dasarZ atasTinggi

Kolom tambahan menyalin segmentasi, material, section, dan rigid link kolom acuan pertama. Rigid link tetap menuju node master yang sama; periksa sambungan kepala kolom dan pilecap setelah mengubah posisi. Beban tidak didistribusikan ulang dan parameter desain tidak dihitung ulang. Bila belum ada acuan, pilih satu section: generator membuat satu BEAM per kolom, tanpa tumpuan atau sambungan otomatis. Unduh MCT untuk menyimpan hasil; periksa model di MIDAS sebelum analisis.

Generator & editor penampang MIDAS

Pilih section model untuk memuat parameter aslinya, ubah nilainya, lalu klik Terapkan & refresh 3D. Elemen yang memakai ID section tersebut ikut berubah. Satuan panjang: M.

Parameter geometri MIDAS

D1/D2 mengikuti urutan parameter MCT untuk SB/SR; pada SR, D1 adalah diameter. Tapered memakai D1/D2 pada masing-masing ujung I–J. H sejajar z lokal dan B sejajar y lokal. Pada section lama, ID, tipe, offset, dan flag MIDAS dipertahankan ketika mengubah dimensi. Untuk mengganti tipe, buat section baru atau gunakan data MCT lengkap.

Input data section dari MIDAS (MCT)

Di MIDAS Civil, ekspor model sebagai MCT, lalu salin satu record penampang beserta baris lanjutannya dari *SECTION atau *SECT-PSCVALUE. Header bagian boleh disertakan. Untuk mengganti section yang dipilih, ID dan jenis bagian harus sama. Pilih sumber “Data MCT dari MIDAS” untuk mengedit teks. Parameter SECTION kompleks, poligon, dan flag tambahan dipertahankan; dukungan volume 3D tetap mengikuti jenis penampang yang didukung.






Tombol “Perbarui tampilan” di panel 3D juga menerapkan draft section yang sedang diedit. Unduh MCT untuk menyimpan perubahan sebelum menutup atau memuat ulang halaman browser.





Cara pakai workspace parametrik
  1. Pilih Geometry untuk n kolom, layout Line/Grid, jarak, rotasi, dan tinggi. Update otomatis menerapkan input valid setelah Anda berhenti mengetik; nonaktifkan untuk memakai Apply model.
  2. Pilih Section atau Material untuk properti penampang dan material. Klik elemen pada model 3D untuk mengganti material, section, atau beta angle.
  3. Gunakan Supports dan Nodal loads untuk constraint DOF dan beban pada load case yang sudah ada. Rigid link, pegas, dan detail kompleks tersedia melalui MCT editor.
  4. Undo membatalkan perubahan model terakhir. Simpan proyek menghasilkan JSON berisi model dan parameter layout untuk dibuka kembali.
  5. Unduh .MCT untuk impor MIDAS Civil. Periksa log impor, sambungan, satuan, penampang dan beban di MIDAS, lalu simpan sebagai .mcb.
